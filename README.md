# 稽核級簽核平台

通用的簽核平台，讓每一個決定都可問責、核准的內容不走樣、紀錄改不掉。各種申請以「流程包」加入，核心不綁定特定領域。

第一版包含兩個流程包：

- **資料授權**：L3、L4 資料的授權申請；核准結果輸出成規則，由 DataCentric（DC）套用。
- **合約用印**：示範用，用來證明核心不綁定領域。
