# 教訓紀錄

格式與規則見 [templates/lessons-log.md](templates/lessons-log.md) 與 [README 第 6 節](README.md#6-越用越聰明)。每個新專案步驟 0 先讀這份。

L1–L10 從第一版 README「犯過的錯」搬來；它們的「訊號」與「為什麼事前沒想到」是搬移時補記的推斷，原紀錄沒有這兩欄。「提煉到哪裡」標「只在文件」的，是下一次要往上提煉的對象。
