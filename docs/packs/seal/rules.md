# 合約用印流程包：業務規則

這是示範用的流程包，用來證明核心不綁定特定領域。規則是為了示範而設計的，不代表任何公司的實際制度；正式使用前要由法務與財務確認。

## 用途

申請在合約上蓋公司印鑑。核准後由印鑑管理人用印，並留下完整紀錄。

## 申請內容

| 欄位 | 說明 |
|---|---|
| 合約名稱 | 文字 |
| 合約對象 | 文字 |
| 合約類型 | 下拉：採購、銷售、保密、租賃、其他（需說明） |
| 合約金額 | 新台幣整數；無金額的合約填 0 |
| 印鑑種類 | 下拉：公司大章、合約專用章 |
| 用印份數 | 正整數 |
| 說明 | 文字 |
| 合約檔案 | 附件，至少一份 |

## 級別

| 級別 | 條件 |
|---|---|
| 一般（`standard`） | 合約金額低於門檻，且印鑑種類是合約專用章 |
| 重大（`major`） | 合約金額達到門檻，或印鑑種類是公司大章 |

門檻是參數，預設新台幣 100 萬元。

## 簽核路徑

| 級別 | 路徑 |
|---|---|
| 一般 | 申請人主管 → 法務 |
| 重大 | 申請人主管 → 法務 → 財務長 |

- 法務：角色群組，由一人認領。
- 財務長：指定一人，可設代理人。
- 核准後由印鑑管理人（角色群組，一人認領）用印，並標記完成。

職責分離、代理、催辦、升級、退回、手機核准都沿用核心的規則。

## 修改

- 縮小：合約金額調降、用印份數減少。
- 其他修改一律視為擴大，包含更換合約檔案、合約對象、合約類型、印鑑種類。

## 這個流程不需要的核心能力

| 能力 | 是否使用 | 原因 |
|---|---|---|
| 有效期間、到期、續期 | 不使用 | 用印是一次性的動作 |
| 被授權者與負責人 | 不使用 | 沒有持續存在的權限 |
| 重複檢查 | 使用：同一申請人、同一合約名稱與對象，已有進行中或已完成的申請時，要求填寫原因 | 避免重複用印 |
| 執行 | 使用：印鑑管理人用印後標記完成，並填寫實際用印份數 | |
| 自動驗證 | 不使用 | |
| 申請人確認 | 使用：申請人確認已領回用印文件，5 個工作天內；逾期只催辦，不撤銷 | 文件已經用印，無法撤銷 |
| 撤銷 | 用印前可以由申請人或任一位簽核人取消；用印後不可撤銷 | |

## 參數

| 參數 | 預設值 |
|---|---|
| 重大合約金額門檻 | 新台幣 1,000,000 元 |
| 催辦、升級時限 | 沿用核心預設 |
| 領回確認時限 | 5 個工作天 |
