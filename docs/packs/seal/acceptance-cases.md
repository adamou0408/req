# 合約用印流程包：驗收案例

三個端對端案例，用來驗收 [contract/03-pack-seal.md](../../contract/03-pack-seal.md)（以下稱「契約」）。規則的來源是 [rules.md](rules.md)。

## 1. 怎麼讀這份文件

- 人員、主管關係與角色用 [contract/seed-directory.md](../../contract/seed-directory.md)，不另外發明人物。
- 基準日是 2026-11-10（星期二）。每一步都寫了假時鐘的時間（台北時間）；執行時先把 `sgn.fake_now` 設成該時間再操作。
- 「畫面」用骨幹第 10 節的通用畫面名稱。這個流程包沒有專屬畫面。
- 「排程」那幾步的執行者是系統：把假時鐘設到該時間後執行一次排程。
- 「預期的稽核事件」用文字描述事件，括號裡是事件要記下的規則代碼。事件的動作代碼以 `01-kernel.md` 為準；規則代碼以契約第 7.2 節與骨幹第 5 節為準。
- 每個案例彼此獨立，只依賴第 2 節的種子資料，可以單獨執行或依任意順序執行。

工作天的算法：這三個案例的時間都選在不論核心用「滿幾個工作天的同一時刻」或「第幾個工作天結束」計算，結果都相同的時點。

| 驗收期間的日期 | 星期 |
|---|---|
| 2026-11-10、11、12、13 | 二、三、四、五 |
| 2026-11-16、17、18、19、20 | 一、二、三、四、五 |
| 2026-11-23、24、25、26、27 | 一、二、三、四、五 |
| 2026-11-30、12-01、02、03、04 | 一、二、三、四、五 |
